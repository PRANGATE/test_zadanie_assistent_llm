# Голосовой ассистент задач и встреч

Локальный прототип для тестового задания «Горький код». Python 3.13 на Windows поддерживается актуальными версиями PyTorch; Transformers ограничен диапазоном `<5`, чтобы не получить непроверенное обновление мажорной версии.

## Возможности

- Ввод текстом и запись по удержанию кнопки мыши.
- Локальный разбор русскоязычного запроса моделью Qwen2.5-1.5B-Instruct.
- Распознавание речи через faster-whisper (модель `small`, CPU/int8 как наиболее предсказуемый вариант Windows).
- SQLite хранит задачи, напоминания и встречи между запусками.
- Создание, список за период, поиск по словам, перенос даты, удаление и отметка выполнения.
- Ответ показывается в истории; системный TTS Windows включён как необязательное озвучивание.
- Каждая операция SQLite использует отдельное соединение. Это устраняет ошибку `SQLite objects created in a thread can only be used in that same thread`.
- UI принимает только один запрос одновременно, но снова становится доступен сразу после завершения обработки, не дожидаясь TTS.

## Требования

- Windows 10/11.
- Python 3.13 (проверено по совместимости заявленных версий библиотек; модельный прогон необходимо подтвердить на конкретном ПК).
- Микрофон для голосового ввода.
- Интернет при первом запуске для скачивания моделей; далее модели работают локально.
- Около нескольких гигабайт свободного места для кэша моделей. Точное потребление зависит от кэша и выбранных библиотек.

## Установка

Из PowerShell в папке проекта:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Если PowerShell блокирует активацию только в текущем окне:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

При первом запуске сначала скачивается Qwen, затем Whisper. Не закрывайте окно до сообщения «Готов к работе». База создаётся в `data/assistant.sqlite3` внутри папки проекта.

## Проверка без загрузки моделей

Из корня проекта:

```powershell
python -m unittest discover -s tests -v
```

Эти тесты проверяют SQLite, межпоточный доступ, сохранение, базовые операции и разбор нескольких дат. Они используют подменную LLM и не требуют скачивания моделей.

## Архитектура

`Tkinter UI → LocalLLM (JSON intent) → AssistantEngine (валидация/даты/бизнес-правила) → Repository (SQLite)`

Голосовой путь: `микрофон → faster-whisper → тот же AssistantEngine → текстовый ответ → системный TTS`.

LLM не выполняет SQL напрямую. Действия выполняет ограниченная бизнес-логика. Вызовы модели сериализованы; UI не блокируется на загрузке моделей, распознавании и генерации.

## Известные ограничения

- Это прототип: напоминания сохраняются, но системные уведомления в заданное время ещё не реализованы.
- Семантический поиск, повторения, календарная синхронизация, несколько пользователей и сложный контекст вроде «перенеси её» не входят в текущую стабильную базовую версию.
- Поиск выполняется по словам, а не по эмбеддингам; формулировки могут требовать совпадения по значимым словам.
- Разбор дат охватывает сегодня/завтра/послезавтра, дни недели, `дд.мм[.гггг]`, а также «через N минут/часов/дней». Неоднозначные даты следует уточнить.
- Whisper запускается на CPU/int8 ради совместимости. Ускорение на GPU можно настроить отдельно после подтверждения корректной работы базового сценария.
- Автоматические тесты не проверяют реальный микрофон, системный TTS, скачивание моделей или инференс Qwen на конкретном компьютере.
