# Отчёт о проверке — Release 1.6.0

Дата подготовки: 2026-10-24.

## Выполнено в рабочей среде

- `python -m unittest discover -s tests -v`: **48 тестов пройдены, 0 ошибок**..
- `python -m compileall -q assistant main.py tests`: синтаксическая компиляция прошла.
- Тестируется новый параметр `dtype` для Transformers `>=4.56.0`; legacy `torch_dtype` применяется только для старых версий ниже этого порога.
- Проверены запросы с «сегодня», «завтра», «послезавтра», днями недели, абсолютными датами, «через N минут/часов/дней».
- Проверены требования даты и точного времени до создания; ответы на уточнения; отмена; отсутствие автоматического сохранения с полуночью/временем по умолчанию.
- Проверены список по периоду без подстановки периода по умолчанию, поиск, семантическое ранжирование через внедрённый тестовый encoder, перенос, удаление, завершение.
- Проверены устойчивость SQLite при обращении из разных потоков и сохранение между экземплярами репозитория.
- Проверены сериализация вывода для TTS без номера `#ID`.
- В архив не должны включаться `data/assistant.sqlite3`, `.venv`, `__pycache__` и локальные кэши моделей.

## Что не было возможно полностью проверить здесь

- Инференс настоящих весов Qwen и faster-whisper, загрузка моделей из Hugging Face, работа реального микрофона и Windows TTS на компьютере пользователя.
- Точность semantic search на большом реальном наборе задач: тестируется взаимодействие с injected encoder, а не качество весов embedding-модели.
- Публичный репозиторий и работающий публичный прототип не созданы. Внешняя публикация требует доступа к аккаунту хостинга и/или созданию web-версии: текущая программа — локальное desktop-приложение Tkinter.

## Ограничения реализации относительно задания

Реализованы локальные задачи/напоминания/встречи, список по датам и периодам, гибридный поиск, постоянное хранение, голосовой ввод, текстовый ответ, опциональный Windows TTS, уточняющий диалог, перенос, удаление и отметка выполнения. Пока не реализованы системные уведомления в запланированное время, конфликты встреч, повторения, календарная интеграция и мультипользовательский режим. Эти пункты частично относятся к дополнительным возможностям в ТЗ; обязательные внешние ссылки остаются задачей публикации.
