# Отчёт о проверке — Release 1.9.1

Дата подготовки: 2026-10-25.

## Выполненные проверки

- `python -m unittest discover -s tests -v`: **73 теста пройдены, 0 ошибок**.
- `python -m compileall -q assistant main.py tests`: проверка синтаксической компиляции прошла.
- Протестированы ответы времени `15:30`, `22:00`, `22 00`, `в 22`, `10 часов вечера`, `10 вечера`, `15 часов 30 минут`.
- Проверено, что «вечером» не считается точным временем, а число в названии «купить 5 яблок» не ошибочно становится временем.
- Проверены незавершённые уточнения: понятные подсказки на ошибочный ввод, прерывание новым запросом, завершение по достижении трёх неудачных попыток без записи в БД.
- Проверены запросы «предложи дату/время»: вариант не записывается без подтверждения; подтверждения «да, хорошо» и «конечно» принимаются; ввод своего значения заменяет предложение; «нет» отклоняет вариант; «не надо»/«отмена» полностью отменяет операцию.
- Проверен случай выбора типа записи «напоминание»: первоначально заданная дата и время сохраняются, ответ типа не трактуется как дата.
- Проверены уточнения создания/переноса, изменение времени при известной дате, отмена, поиск, список активных дел, семантический поиск и SQLite.
- Архив собирается без `data/assistant.sqlite3`, `.venv`, кэшей моделей и `__pycache__`.

## Ограничения

- Для большей части тестов используются fake LLM/encoder и временная база. Один тест проверяет интеграцию метода предложения модели через подмену метода валидированным кандидатом; реальная генерация предложения Qwen не тестировалась end-to-end в этой среде.
- Полноценный запуск Qwen, faster-whisper, микрофона и Windows TTS должен быть проверен на целевом Windows-ПК.
- Публичный репозиторий и веб-прототип не опубликованы.
- Не реализованы реальные системные уведомления, поиск конфликтов, повторения, календарная интеграция и multi-user.

## Ручная проверка на Windows

1. `Добавь задачу на завтра сходить в парк` — ожидается уточнение времени с форматами `15:30`, `22:00`, `10 часов вечера`.
2. В ответ отправить `10 часов вечера` — задача должна создаться на завтра в 22:00.
3. Повторить создание, затем на вопрос о времени ввести `не знаю` трижды — уточнение должно завершиться без записи.
4. На вопрос о времени ввести `предложи время` — ассистент предложит кандидат. До подтверждения `да`, `да, хорошо` или `конечно` запись не появляется.
5. На вопрос об ожидаемом времени вместо ответа ввести `покажи активные дела` — ожидающее создание отменяется, выполняется новая команда.
6. Запросить предложение три раза и ответить `нет` на каждый вариант — после третьего отказа уточнение завершается без записи.
7. При активном предложении ответить `не надо` — весь незавершённый процесс отменяется.
6. `Создай купить молоко завтра в 15:00` → ответ `напоминание` — должно создать напоминание на указанную дату/время.
