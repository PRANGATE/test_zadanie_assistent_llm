# История изменений

## 1.9.1 — 2026-10-25

- Уточнения принимают естественное подтверждение предложения: «да, хорошо», «конечно», «подходит».
- «Не надо» отменяет незавершённую операцию даже после предложения ИИ; три подряд отклонённых предложения завершают диалог без записи, чтобы не создавать бесконечный цикл.
- Исправлено предложение времени для записи на сегодня поздно вечером: приложение больше не предлагает время, которое уже прошло.
- Добавлены регрессионные тесты для этих сценариев. Итоговая проверка: 73 автоматических теста и компиляция пройдены.

## 1.9.0 — 2026-10-25

- Исправлено зацикливание уточнения времени/даты: ответы сначала проверяются как ожидаемое поле, а при нераспознанном ответе даются примеры и альтернативы, а не молча повторяется тот же запрос.
- Расширено распознавание точного времени: `15:30`, `22:00`, `22 00`, `в 22`, `10 часов вечера`, `10 вечера`, `15 часов 30 минут`. Число внутри названия (например, «купить 5 яблок») само по себе не воспринимается как время.
- После трёх неудачных попыток незавершённое создание/изменение отменяется; запись не создаётся и не изменяется. Явная новая команда прерывает ожидающее уточнение.
- Добавлена команда `предложи дату/время`: локальная LLM предлагает вариант в ограниченном формате, результат проверяется кодом и применяется только после явного подтверждения «да». Если LLM недоступна или ответ не проходит проверку, предлагается явно обозначенный запасной вариант, также требующий подтверждения.
- Добавлены короткие инструкции в UI о форматах даты/времени, предложениях и отмене. Подтверждение предложения понимает естественные ответы «да, хорошо», «конечно» и «подходит»; «не надо» отменяет операцию полностью.
- Исправлен переход после ответа на уточнение типа «задача/напоминание/встреча»: выбранный тип больше не переинтерпретируется как дата.
- Добавлены регрессионные тесты на разговорные ответы времени, подсказки, подтверждение/отклонение предложений, прерывание новым запросом, ограничение числа попыток и защиту от ложного времени в названии.
- Итог для 1.9.0: 68 автоматических тестов пройдены; `compileall` прошёл.

## 1.8.0 — 2026-10-25

- Исправлен перенос существующей встречи/задачи, когда пользователь задаёт только новое время. Если у записи уже есть дата, она сохраняется; дата не запрашивается повторно.
- Улучшен поиск цели изменения: учитывается полное название из запроса даже при ошибочном типе записи, возвращённом LLM.
- При явном слове «встреча/встречу/созвон» поиск цели направляется к встречам.
- Добавлены регрессионные тесты по отзыву тестировщика.

## 1.7.0 — 2026-10-25

- Исправлена команда вывода активных дел/задач; добавлено изменение названия записи; улучшена маршрутизация изменения даты/времени.

## 1.6.0 — 2026-10-24

- Устранено предупреждение Transformers о deprecated `torch_dtype` для актуальных версий API.
- Исправлены кейсы дат/времени, обработка диалога и UI-потоков.

## Известные незакрытые пункты

- Публичный репозиторий и веб-прототип ещё не опубликованы.
- Не реализованы планировщик уведомлений, конфликт-детектор, повторяющиеся записи, календарная интеграция и многопользовательский режим.
- Требуется локальная end-to-end проверка настоящих моделей, микрофона и Windows TTS.
