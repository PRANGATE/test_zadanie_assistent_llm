# История изменений

## 1.7.0 — 2026-10-25

- Исправлена команда вывода активных дел/задач: детерминированно выбирается список, исключаются выполненные записи, поддерживается отбор по периоду.
- Добавлено изменение названия записи. Поддерживаются названия в кавычках и фразы без кавычек, если название существующей записи явно присутствует в запросе.
- Улучшено изменение срока: «измени дату/время» и «перенеси» распознаются как перенос даже при ошибке классификации LLM.
- Неполная команда редактирования вызывает уточняющий вопрос, а не общий отказ. Неоднозначный выбор записи не выполняется автоматически.
- Добавлены регрессионные тесты: 57 тестов проходят.


## 1.6.0 — 2026-10-24

- Устранено предупреждение Transformers о deprecated `torch_dtype`: используется `dtype` в актуальных версиях API с совместимым fallback для старых версий.
- Расширена обработка относительных сроков, дат и названий; исправлены кейсы «послезавтра», длительности «через два часа/два дня» и удаление временных выражений из заголовка.
- Без даты, точного времени или периода больше нет незаметных значений по умолчанию: пользователь получает уточняющий вопрос.
- Уточнение создания/переноса не должно записывать данные, пока недостающие поля не сообщены.
- Обновлён UI dispatch в главный поток Tkinter; микрофон и отправка включаются после загрузки моделей.
- Добавлены регрессионные тесты, README и отчёт с честным описанием ограничений.
- Исключены локальная SQLite-база с тестовыми записями и устаревшие заметки предыдущих версий из дистрибутива.

## Известные незакрытые пункты

- Публичный репозиторий и веб-прототип ещё не опубликованы.
- Не реализованы планировщик уведомлений, конфликт-детектор, повторяющиеся записи, календарная интеграция и многопользовательский режим.
- Требуется локальная end-to-end проверка реальных моделей, микрофона и Windows TTS.
