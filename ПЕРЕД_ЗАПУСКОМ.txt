ИСПРАВЛЕНИЕ ПО РЕЗУЛЬТАТАМ ЛОКАЛЬНОГО ТЕСТА

Исправлены два сценария:
1) При создании задачи дата вроде «на завтра» теперь извлекается из исходного текста, если языковая модель не заполнила date_text.
2) Вопрос «Какая задача на завтра?» и аналогичные вопросы о планах за период принудительно обрабатываются как список за соответствующий период, даже если LLM классифицирует их как поиск по ключевым словам.

Установка (PowerShell из папки проекта):
  py -3.13 -m venv .venv
  .\.venv\Scripts\Activate.ps1
  python -m pip install --upgrade pip
  pip install -r requirements.txt
  python -m unittest discover -s tests -v
  python main.py

Не удаляйте старую папку проекта, пока не проверите новую сборку. База данных хранится в подпапке data рядом с main.py.
