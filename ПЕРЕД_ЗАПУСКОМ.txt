ГОЛОСОВОЙ АССИСТЕНТ — RELEASE 1.9.1

УСТАНОВКА (PowerShell из папки проекта):
  py -3.13 -m venv .venv
  .\.venv\Scripts\Activate.ps1
  python -m pip install --upgrade pip
  pip install -r requirements.txt
  python -m unittest discover -s tests -v
  python main.py

При первом старте скачиваются локальные модели; дождитесь статуса «Готово».
База создаётся автоматически в data\assistant.sqlite3. Архив не содержит данных пользователя.

МИНИ-ИНСТРУКЦИЯ:
- Дата: «сегодня», «завтра», «послезавтра», «в пятницу», «26.10.2026».
- Время: «15:30», «22:00», «22 00», «10 часов вечера», «15 часов 30 минут».
- Не говорите только «вечером/утром/в обед» — укажите конкретные часы и минуты.
- Для варианта напишите «предложи дату» или «предложи время». Предложение не применяется до подтверждения: подойдут «да», «да, хорошо», «подходит» или «конечно». Ответ «нет» отвергает только предложенный вариант; «не надо» и «отмена» прекращают операцию.
- Для отмены незавершённого уточнения введите «отмена». Новая команда тоже может прервать ожидающий вопрос.
- После трёх ответов, которые нельзя разобрать, или трёх отклонённых предложений незавершённое действие отменяется, данные не записываются.
- Если STT ошибается, введите ответ текстом в строке ввода.

ОБНОВЛЕНИЕ С СОХРАНЕНИЕМ ЗАПИСЕЙ:
1) Закройте приложение.
2) Скопируйте data\assistant.sqlite3 в резервное место.
3) Распакуйте архив поверх проекта, заменяя файлы кода, но не удаляйте каталог data.
4) Если распаковали в новую папку, создайте в ней data и скопируйте туда старый assistant.sqlite3.
5) Активируйте прежнее виртуальное окружение (или установите зависимости), выполните тесты и запустите main.py.

Автоматические тесты используют временную БД и не загружают большие модели.
Публичная ссылка на веб-прототип пока отсутствует; это локальное desktop-приложение.
Подробности см. README.md, CHANGELOG.md и TEST_REPORT.md.
