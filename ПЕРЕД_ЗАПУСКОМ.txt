ГОЛОСОВОЙ АССИСТЕНТ — RELEASE 1.7.0

1) Распакуйте архив в новую папку (например F:\gorky_assistant_1_7).
2) Откройте PowerShell в этой папке и выполните:

   py -3.13 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   python -m unittest discover -s tests -v
   python main.py

При первом запуске загрузятся модели. Дождитесь статуса «Готов к работе».
База создаётся автоматически в data\assistant.sqlite3. Архив намеренно не содержит
базы с тестовыми записями или пользовательскими данными.

ПРАВИЛО: без явной даты и точного времени ассистент должен уточнить недостающие поля,
не сохранять задачу с полуночью или условным временем. Расплывчатое «утром/вечером/в обед»
не является точным временем. Если период списка не указан, ассистент должен спросить.

Тесты выполняются без загрузки LLM/Whisper:
   python -m unittest discover -s tests -v
   python -m compileall -q assistant main.py tests

Публичная ссылка на репозиторий и веб-прототип не включена: они не были опубликованы.
Смотрите README.md и TEST_REPORT.md для состава функций, проверок и ограничений.


Обновление поверх предыдущей версии:
- Закройте приложение.
- Сначала скопируйте data\assistant.sqlite3 в резервное место.
- Распакуйте архив поверх папки проекта, разрешив замену файлов кода, но не удаляйте папку data.
- Если распаковали в новую папку, скопируйте прежний data\assistant.sqlite3 в новую папку data.
- Запустите тесты и приложение заново.
